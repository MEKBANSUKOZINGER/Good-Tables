# Good Tables

기존 Markdown 표에 서식·색상·대각선·병합 기능을 추가하는 Obsidian 데스크톱 플러그인입니다. 기본 표 편집기를 유지합니다. 버전 0.2.1은 Obsidian 1.14.4 이상을 대상으로 합니다.

[English](README.md) · [변경 기록](CHANGELOG.md)

0.1.2에서는 번호 버튼을 제거하고 옵시디언 기본 행·열 선택기를 사용합니다. 기본 서식·정렬·클립보드 및 다른 플러그인의 메뉴를 보존하고, 구분선 아래에 Good Tables를 추가합니다. 0.1.1의 별점·선택 해제·하위 메뉴 닫기 수정도 포함합니다.

0.1.3은 기본 행·열 이동에 서식·색상·크기·제목 지정이 함께 따라가도록 저장 기준을 갱신합니다. 표와 확장 정보를 같은 편집 작업에 담아 기본 실행 취소·재실행도 함께 처리합니다. 같은 값의 행이나 빈 열은 실제 이동 시작점과 도착점을 확인해 구분합니다.

이동으로 병합이 직사각형을 이루지 못하면 해당 병합만 취소하고 모든 원본 칸과 서식을 유지합니다. 대각선 칸이 첫 칸에서 벗어나면 대각선 표시는 해제하고 연결된 원본 텍스트를 유지합니다. 이 변화도 이동과 함께 실행 취소됩니다.

## 사용

1. 리본의 표 아이콘 또는 명령 팔레트의 **Good Tables: 표 만들기**를 실행합니다. 단축키는 Obsidian 설정에서 직접 지정합니다.
2. 행·열 수는 전체 크기입니다. 제목 행·열은 자동 지정하지 않습니다.
3. 셀을 드래그해 범위를 선택하거나 표 위·왼쪽의 옵시디언 기본 선택기로 열·행을 선택합니다. 기본 선택기를 드래그하는 행·열 이동도 유지합니다.
4. 선택 영역 안을 우클릭하면 기본 메뉴가 먼저 표시되고 구분선 아래에서 현재 선택에 적용할 수 있는 제목·서식·병합·색상 기능을 사용합니다. 기본 메뉴 항목은 셀의 선택·편집 상태에 따라 달라집니다.
5. 서식 셀은 기본 편집기로 원본을 편집합니다. 병합 셀은 더블클릭하거나 **원본 값 편집**을 사용합니다. 대각선 칸은 왼쪽 아래·오른쪽 위 입력란을 클릭해 바로 입력하며 줄바꿈도 지원합니다.
6. 문서 편집은 기본 실행 취소·재실행을 사용합니다. 설정 변경은 기존 표에도 즉시 반영되며 문서 실행 취소에는 포함되지 않습니다.

## 설치와 빌드

0.2.1에서는 기본 셀 편집기가 클릭 시 지우는 색상 스타일을 즉시 복구합니다. 한 칸의 병합·첫 칸 이외의 대각선처럼 적용할 수 없는 메뉴를 숨기고, Good Tables의 행·열 편집 및 칸 크기 메뉴·추가 조절 핸들을 제거했습니다. 기본 Obsidian 표 도구는 계속 사용합니다.

색상 창에서 현재 적용된 색과 선택한 색을 비교할 수 있고, 자주 쓰는 색 편집에서는 선택 항목에 테두리가 나타납니다. 제목 배경·글자색은 설정창에서도 실제 색 미리보기를 표시합니다. 일반 **사용자 지정** 서식은 메뉴와 순서 설정의 맨 아래에 고정합니다.

0.2.0에서는 표 갱신 때 기존 서식 요소를 재사용하고 다음 화면 표시 전에 반영하여 크기·서식이 잠깐 사라지는 현상을 수정했습니다. 한 셀을 편집하다 우클릭하는 비동기 기본 메뉴에도 Good Tables 항목을 추가합니다.

색상 선택 창에는 채도·밝기 영역과 색조 막대가 바로 표시되며 HEX·RGB 입력이 함께 바뀝니다. **새 표 기본값**에는 행·열 수와 첫 칸 대각선만 남기고, 나머지는 **표 설정**으로 묶었습니다. 제목 배경·글자 색은 HEX 입력란과 색 선택기를 제공합니다. 자주 쓰는 사용자 서식은 서식 메뉴에 개별 항목으로 나타나며 **서식 메뉴 순서**에서 각각 이동할 수 있습니다.

[GitHub Releases](https://github.com/MEKBANSUKOZINGER/Good-Tables/releases)에서 `main.js`, `manifest.json`, `styles.css` 세 파일을 받아 볼트의 `.obsidian/plugins/good-tables/`에 복사하고 Obsidian에서 활성화합니다. 설치용 `good-tables-0.2.1.zip`에는 같은 파일들이 `good-tables/` 폴더에 들어 있습니다. GitHub가 자동 생성하는 소스 압축 파일은 먼저 빌드해야 합니다.

소스에서 직접 빌드하려면 다음 명령을 실행합니다.

```sh
npm ci
npm run lint
npm run build
npm test
npm run package
```

`release/good-tables/`의 `main.js`, `manifest.json`, `styles.css`를 볼트의 `.obsidian/plugins/good-tables/`에 복사하고 Obsidian에서 활성화합니다.

## 저장 방식

내용은 일반 Markdown 표에 유지합니다. 병합에서 가려진 칸도 원본 표에 남습니다. 확장 정보는 표 다음의 빈 줄 아래에 `[good-tables-…]: good-tables:…` 형식의 사용하지 않는 Markdown 참조 정의로 저장합니다. 읽기 보기에는 나타나지 않으며, 플러그인이 라이브 프리뷰에서도 숨깁니다. 소스 모드에서는 전체를 확인할 수 있습니다.

표를 옮길 때에는 연결된 참조 정의도 함께 옮겨야 합니다. 플러그인을 끄면 일반 표로 표시되고 확장 표시만 사라집니다. 최초 사용 안내와 비활성화 알림을 제공합니다.

동시에 여러 구조를 바꾸어 기존 칸의 대응을 확인할 수 없으면 확장 정보를 보존한 채 적용을 중단합니다. 이때 구조 변경을 실행 취소하거나 **이 표의 Good Tables 정보 초기화**를 사용합니다. 초기화도 실행 취소할 수 있습니다.

계산 규칙과 개발용 설치·실제 앱 검증 방법은 [영문 README](README.md)를 참고하세요.

## 0.1.4 검사 대응

Obsidian 설정 검색에서 항목을 찾을 수 있도록 설정 API를 갱신했습니다. 별도 창의 타이머·DOM 생성 방식을 정리하고 직접 스타일 지정·불필요한 타입 단언·미사용 변수·CSS의 `!important`를 제거했습니다. 설정값과 기존 표의 저장 형식은 유지합니다.

## 데이터와 클립보드

Good Tables는 로컬에서 동작하며 네트워크 요청이나 사용 정보 전송을 하지 않습니다. 표 편집은 Obsidian 편집기를 통해 저장하고, 설정은 플러그인 데이터 API로 저장합니다.

**원본 값 복사**는 선택한 칸의 원본 값을 탭으로 구분해 시스템 클립보드에 씁니다. **여러 셀 붙여넣기** 창과 다중 선택 붙여넣기는 사용자가 제공한 텍스트의 탭·줄바꿈을 열·행으로 해석합니다. 백그라운드에서 클립보드를 읽지 않으며, Obsidian 전용 표 클립보드 데이터는 기본 처리에 맡깁니다.

## 배포 검증

`npm run lint`로 공식 Obsidian 규칙을 검사합니다. GitHub Actions의 **Build and attest release assets**를 수동 실행하면 빌드·테스트·출처 증명을 거친 설치 파일을 받을 수 있습니다. 출처 증명을 사용하려면 그 결과물의 압축을 풀어 나온 세 파일을 그대로 Release Assets에 올립니다. 워크플로는 Release를 자동 발행하지 않습니다.
